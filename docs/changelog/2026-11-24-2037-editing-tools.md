# Editing tools on the canvas

- New tools on `CanvasController`: `Tool.SHAPE`, `Tool.LINE` and `Tool.TEXT` join pen, eraser, pan and select, with settings mirroring the editor's menus: `eraserMode`, `selectMode`, `shapeKind`, `shapeFill`, `constrainShapes`, `lineArrows`, `arrowhead`, `snapAngles` and `textSize`. The pen's cycle button now reaches a working select tool.
- Partial eraser: `EraserMode.PARTIAL` cuts strokes where the eraser passes and keeps the rest as new strokes with fresh ids ([2026-11-24-2037-partial-eraser-splits-point-lists](../adr/2026-11-24-2037-partial-eraser-splits-point-lists.md)). Whole-stroke erase stays the default.
- Select: a pen lasso or rectangle selects what it encloses or touches, and a tap picks the element under the pen, tested against outlines ([2026-11-24-2037-lasso-selects-what-it-touches](../adr/2026-11-24-2037-lasso-selects-what-it-touches.md)). The selection shows a box with four corner handles. Dragging inside moves it; dragging a handle scales it uniformly about the opposite corner, with stroke, outline and line widths and font sizes scaling too. Delete, duplicate, select all and the four stacking commands are controller calls.
- Shapes: rectangles and ellipses by dragging corner to corner, in the current colour and width with an optional fill; `constrainShapes` makes squares and circles. Lines: straight, with no arrowhead, one at the end or both, snapped to 15° steps while `snapAngles` is on.
- Text boxes: a tap with the text tool creates a box and opens an `EditText` over it with the markdown source; a tap on a box edits it. A touch elsewhere, Back, a tool change or undo commits. The frame's height becomes the renderer's `measureHeight` ([2026-11-24-2037-text-boxes-edited-in-place](../adr/2026-11-24-2037-text-boxes-edited-in-place.md)).
- Moves, scales, drafts and the lasso are drawn by the canvas view over the note (`ScenePreview`, `SceneRenderer.draw`'s new optional parameter) and change the note once, at pen-up, as one undo step. In-progress ink and `LowLatencyCanvasView` are unchanged.
- The geometry is in `:core` (`app.screenscratch.core.edit`): plane maths, partial erase, lasso and tap hit tests, element transforms and snapping, ported with citations from xnotes and Excalidraw (MIT).
- The canvas test screen has buttons for every tool, its options and the selection commands.
- Tests: unit tests for the split-erase geometry, point-in-polygon and lasso membership, move and scale maths, angle snapping, stacking and undo/redo of every tool through the controller, and input routing of the new tools. Robolectric renders shapes, lines, the selection box and handles, a move and a scale in progress, a lasso, a draft and a partial erase to `app/build/outputs/canvas-render/tools-*.png`. On the API 35 tablet emulator, injected stylus events lasso-select and move a stroke, draw a rectangle, partially erase a stroke and create and edit a text box.
