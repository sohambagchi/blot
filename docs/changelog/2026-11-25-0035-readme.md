# README front page

- `README.md` opens with a banner (logo, name, tagline, dot grid, three ink strokes), badges, the library screenshot, a features list and a screenshot grid, followed by the existing Develop section and a Licence section with the third-party credits
- The logo is the launcher icon's "blotted b" ported by hand to SVG, in light and dark; banner and screenshots switch with GitHub's colour scheme through `<picture>`
- `assets/readme/` holds the SVGs and nine compressed screenshots (about 250 KB), taken from the Robolectric renders in `app/build/ui-shots` and `app/build/outputs/canvas-render`
- The features list names only what the changelogs confirm; image import is listed as still to come
