# Screen Scratch is now Blot

- The launcher shows "Blot"; the application ID is `app.blot`, and an install sits beside any old `app.screenscratch` one
- Kotlin packages moved to `app.blot.*`; theme and icon types are `BlotColors`, `BlotType`, `BlotTheme`, `BlotIcons`
- README, TODO, INDEX, the flake and `.arty` use the new name; dated records keep the old one
- Rationale: see ADR [2026-11-24-2125-rename-to-blot](../adr/2026-11-24-2125-rename-to-blot.md)
