# App shell: library, editor, storage and canvas joined

- `MainActivity` is the app: the folder prompt on first run (the system tree picker through `NoteFolder`), then the library listing the folder's notes through `TreeNoteStore` on `SafFileTree`, then the editor. Navigation is a state in `app.screenscratch.shell.AppModel`; back returns to the library. A lost folder grant shows the re-grant prompt.
- New notes: infinite canvas, A4, Letter, or a page the size of the screen, from the library's new-note button. The page chip in the editor opens a page menu: kind, landscape, add or remove a page.
- `CanvasEditor` maps the chrome's actions to `CanvasController` (tool, pen mode, colour, width, "Pen only", undo, redo, page setup, zoom reset) and lays the canvas's live state over the chrome's: the pen's side-button cycle shows on the toolbar, undo, redo and zoom follow the canvas. Shape, line, text and image tools select nothing on the canvas until those tools exist.
- Saves are debounced to 1 s after the last edit and flushed when leaving the editor and in `onStop`, on one I/O thread shared with the library, through `NoteJson`. A failed save says so over the canvas and retries on the next save. A note opened from `note.json.tmp` says so once; one whose `note.json` is from a newer app opens read-only from its backup.
- Thumbnails are drawn with the canvas's `SceneRenderer` after each save and cached in app storage, apart from the notes folder ([ADR](../adr/2026-11-24-2043-thumbnails-outside-the-library-index.md)).
- Text boxes render through `MarkdownLayout` with export's settings (theme with the box's colour, its font size as base size, density 1), cached per box, source, width, colour and theme. Images come from the note's `assets/` as software bitmaps.
- Settings persist the theme (applied to the chrome, the canvas and thumbnails), the side-button swap, and "Pen only", which defaults on only for a tablet-sized screen with a stylus. A long-press on About shows the developer section: the pen test, canvas test and UI preview, and the front-buffer mode, which defaults to ink only ([ADR](../adr/2026-11-24-2043-front-buffer-holds-ink-only-by-default.md)).
- The chrome stays inside the safe-drawing insets while the canvas runs edge to edge. The toolbar moves off the corner pills and the page chips when it would cover them. Swatches use the canvas's dark-mode ink transform.
- Exports go through an `Exporter` interface; until export is joined in, it answers "Export isn't available yet".
- Canvas change: `CanvasController.redraw()`, for text-box images that finish loading.
- Tests: Robolectric for the action mapping, autosave timing, thumbnail keys and rendering, settings, the text-box cache and the toolbar's placement. On the API 31 tablet emulator: create a note, draw a stylus stroke, see it listed with its thumbnail, reopen it, relaunch, and lose the folder grant.
