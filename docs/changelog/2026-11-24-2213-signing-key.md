# Builds are signed with Blot's own key

- Debug and release APKs sign with `~/.android/blot.jks` (certificate SHA-256 `6be26060…31bc18`), so each build installs over the last
- `signing.properties` (untracked) overrides the store path and password; without the key, builds use the debug key
- README says how to create the key
- Rationale: see ADR [2026-11-24-2213-fixed-signing-key-outside-the-repo](../adr/2026-11-24-2213-fixed-signing-key-outside-the-repo.md)
