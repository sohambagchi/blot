# Export to PNG, PDF and SVG, and share

- `app.screenscratch.export.NoteExporter` exports a note as PNG, PDF or SVG to an `OutputStream`. PNG and PDF draw every element through the canvas's `SceneRenderer.drawElement` and text boxes through `MarkdownLayout.draw`, so exports look as they do on screen. PDF stays vector: strokes are filled paths and text is text.
- `ExportOptions` (in `:core`, `app.screenscratch.core.export`) covers format, range (whole note, area, selection, page range), paper or transparent background, dark export, dot grid, PNG scale, margin and a pixel budget. `exportOptionsFor` maps the editor dialog's choices to it. A dark export uses `InkColors.darkMode` on the dark page.
- Page notes: one PDF page per note page (A4 is 595 × 842 pt). PNG and SVG stack the pages in one file. An infinite canvas exports its content bounds plus a 24 dp margin. See [export pages and bounds](../adr/2026-11-24-2023-export-pages-and-bounds.md).
- `SvgNoteWriter` (`:core`, pure Kotlin) is our own writer; no code was ported. It emits strokes as filled outline paths, shapes, lines with arrowheads, images as `data:` URIs, and text boxes as `<text>`/`<tspan>` per laid-out line plus the markdown decorations. It uses no `foreignObject`. See [SVG embeds images](../adr/2026-11-24-2023-svg-embeds-images.md).
- `ExportFiles` writes to `cache/exports/` and shares through the existing FileProvider (`file_paths.xml` gained an `exports` path). It can also write to a user-picked document. `ExportLauncher` wires "Share…" and "Save to folder" (`CreateDocument`) for an activity.
- Tests: core unit tests parse the SVG back and check the viewBox, element counts, arrowheads, escaping, pages and selection. Robolectric tests export a sample note with every element type, light and dark, as PNG and SVG to `app/build/exports/`, check pixels, and check the share intent. The SVGs render in librsvg as they do in the PNG. `PdfExportTest` (instrumented) checks page counts and sizes; it compiles but has not yet been run on a device.
- No new dependencies.
