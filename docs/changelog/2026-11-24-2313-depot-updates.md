# Blot updates itself from depot

- Builds from the dev shell carry depot's client: a check every 6 hours, a "Blot X is ready" notification, and installs without a system dialog after "Install unknown apps" is allowed once
- `versionCode` is the commit count and `versionName` comes from the newest `[X.Y.Z]` commit subject
- Publish with `emu-publish app/build/outputs/apk/release/app-release.apk` from a clean tree; the first check on a device needs Tailscale on, to enroll
- Rationale: see ADR [2026-11-24-2313-updates-through-depot](../adr/2026-11-24-2313-updates-through-depot.md)
