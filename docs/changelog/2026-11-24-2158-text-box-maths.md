# Text boxes fit their markdown and render LaTeX maths

- A committed text box is as tall as its rendered markdown; before, it kept the text tool's one-line frame and clipped everything below the first line
- Heights are fitted again whenever the note changes (load, edit, undo, resize, an image loading), so boxes saved with a clipped height heal on open
- `$…$` renders inline maths and `$$…$$` display maths, centred on its own line; long inline maths wraps after operators and relations
- Dollar amounts such as "costs $5 and $6", `\$`, code spans and code blocks stay text
- Supported: fractions, sub/superscripts and primes, roots, Greek, operators and relations, big operators with limits, `\left…\right`, `pmatrix`/`bmatrix` and other matrices, `\text{}`, accents, `\mathbb`, `\mathcal`, `\mathbf`, `\mathfrak` and friends
- LaTeX that doesn't typeset shows its source in the muted colour with a red underline
- Screen, thumbnails, PNG, PDF and SVG draw the same glyph outlines; SVG maths is `<path>` elements that need no font
- Settings → About lists the bundled Blot Math font (Latin Modern Math subset, GUST Font License) and the MIT typesetter port, with their full licences
- Rationale: see ADR [2026-11-24-2158-text-box-maths-ported-typesetter](../adr/2026-11-24-2158-text-box-maths-ported-typesetter.md)
