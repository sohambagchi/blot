# The app is called Blot

**Status:** accepted

**Context:** "Screen Scratch" was a working title.
**Decision:** The app is Blot: launcher label "Blot", application ID `app.blot`, Kotlin packages `app.blot.*`, Gradle project `blot`. Dated ADRs, changelogs and reports keep the old name as written.
**Alternatives:** Rename only the launcher label — leaves two names in the code for good.
**Consequences:** A device sees `app.blot` as a new app, so the notes folder is picked again; notes on disk are unaffected. The repository directory and the claude.ai artifacts keep their old names until renamed separately.
