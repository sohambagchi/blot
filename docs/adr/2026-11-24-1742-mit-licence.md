# MIT licence

**Status:** accepted

**Context:** The licence decides which open-source code we may port. The useful references (perfect-freehand, xnotes, Excalidraw) are MIT; the GPL note apps are Rust, Dart or C++, so copying from them would be a rewrite anyway.
**Decision:** The project is MIT-licensed (`LICENSE` at the root).
**Alternatives:** GPL-3.0 — would allow copying from Rnote, Saber, Notable and Xournal++, which gains little across languages. Apache-2.0 — fine, but its patent clause and `NOTICE` handling add nothing for a personal app.
**Consequences:** GPL, AGPL and source-available code (tldraw) is read for approach only, never copied. Ported MIT/Apache code keeps its upstream copyright line in a comment beside it.
